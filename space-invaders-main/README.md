## Instalação e execução

Para executar o projeto, é necessário ter instalado:

- Visual Studio Code
- GCC / MinGW
- Biblioteca Raylib

### Passo a passo

1. Faça o download ou clone este repositório:

   ```bash
   https://github.com/fCosmoski/space-invaders.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.

3. Certifique-se de que o GCC e a biblioteca Raylib estejam instalados e configurados corretamente.

4. Caso necessário, ajuste os caminhos da biblioteca Raylib nos arquivos de configuração do projeto (`tasks.json` e `c_cpp_properties.json`).

5. Compile e execute o projeto utilizando a tarefa de compilação configurada no VS Code.

## Como jogar

1. Ao iniciar o jogo, será apresentada a tela inicial.
2. Clique no botão **JOGAR** para iniciar a partida.
3. Durante o jogo, acompanhe a pontuação exibida na tela.
4. Para encerrar o jogo, utilize o botão **SAIR** na tela inicial ou feche a janela.
